# POSYDON-2026-School-Labs

These are coding exercises (primarily Jupyter notebooks) from the POSYDON School 2026.
These are aimed to teach users how to use populaiton synthesis code POSYDON for astrophysics research.
We recommend going day by day, starting with the labs from Tuesday morning to learn the basics 
-- or if you are already familiar with POSYDON, jump in wherever suits your needs.

## Precomputed data

Some of these labs rely on pre-made population data to work.
The requisite population data can be downloaded from Zenodo here: https://zenodo.org/records/22823443.

## Presentations

During the school, several physics introductions and code structure talks were given.
We've made the slide available on the [Zenodo repository](https://zenodo.org/records/22823443) as well.
